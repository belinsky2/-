# Punchline (веб)

Приложение для работы над шутками по методу Джуди Картер.

## Зачем веб, если телефон Android

Не ради универсальности. Ради обратной связи: Android-версию нельзя было
запустить нигде, кроме телефона автора, — каждая проверка гипотезы стоила
установки APK вручную. Здесь сценарий прогоняется целиком за десять секунд,
со скриншотами, до того как сборка кому-то отдаётся.

Побочные выгоды: доставка ссылкой вместо APK, и тот же код на Mac, когда
дойдут руки.

## Команды

    npm install
    npm test        # домен и правила архива
    npm run build   # типы + сборка
    npm run dev     # разработка

    npm run preview &   # слушает именно 127.0.0.1, а не localhost
    npm run shots       # прогон сценария, картинки в web/shots/

## Устройство

    src/domain/   правила из книги. Перенесены из core/model (Kotlin) вместе
                  с тестами: Kotlin-версия остаётся эталоном при расхождении.
    src/store/    IndexedDB, единая точка записи, архив материала.
    src/ui/       экраны. Весь видимый текст — в labels.ts.

## Решения, которые не стоит отменять не подумав

- **Поля синхронизации у каждой записи.** `updatedAt`, `lamport`, `deviceId`,
  `deletedAt` заполняются всегда, даже пока синхронизации нет. Добавить их
  задним числом к накопленному материалу нельзя: у старых записей неоткуда
  взять историю, и при первом же слиянии с Mac часть правок потеряется.
- **Удаление — надгробие, а не удаление строки.** Физически удалённая запись
  на втором устройстве выглядит просто отсутствующей и воскресает.
- **Архив — один JSON, а не zip.** Проверено на человеке: архив из нескольких
  файлов на телефоне не открывается и выглядит как ошибка.
- **Автоэкспорт в момент правки.** Скачивание браузер разрешает в ответ на
  действие человека; в фоне оно тихо не сработает.
- **Весь текст в `labels.ts`.** Строки, расползшиеся по коду, потом не
  переформулировать разом.

## Публикация

Один раз вручную: **Settings → Pages → Source → GitHub Actions**. Токен
рабочего процесса включить Pages не может, права на это у него нет.

После этого каждый пуш в ветку разработки публикует новую версию
автоматически — но только если прогон сценария прошёл.
