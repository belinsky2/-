# Проект на Mac

Инструкция для одного раза. Дальше обновление — одна команда (`git pull`).

## Что стоит понимать заранее

- **Твой материал на компьютере не появится.** Шутки, темы и дневник живут
  в браузере телефона. Приложение, запущенное на Mac, — отдельная пустая копия
  с отдельной базой. Перенести материал можно архивом: Настройки → «Сохранить
  архив сейчас» на телефоне, затем «Восстановить из архива» на Mac.
- **Разработка идёт в облаке**, через Claude. Копия на Mac нужна, чтобы
  код был у тебя, чтобы смотреть изменения до публикации и чтобы работать
  без облака, если понадобится.

## 1. Git

Открой «Терминал» (Программы → Утилиты → Терминал) и выполни:

    xcode-select --install

Появится окно установки инструментов разработчика — согласись. Если пишет,
что уже установлено, всё в порядке. Проверка:

    git --version

## 2. Node.js 22

Скачай установщик **Node.js 22 (LTS)** с https://nodejs.org — вариант для
macOS, файл `.pkg` — и установи как обычную программу. Нужна именно 22-я
версия: на ней проект собирается в облаке, и на другой версии результат может
отличаться. Проверка:

    node --version     # должно начинаться с v22

## 3. Скачать проект

Папка для проектов — например, `Projects` в домашней папке:

    mkdir -p ~/Projects
    cd ~/Projects
    git clone https://github.com/belinsky2/punchline.git
    cd punchline/web
    npm ci

`npm ci` ставит зависимости ровно тех версий, что записаны в
`package-lock.json`, — так же, как в облаке.

## 4. Запустить

    npm run dev

Открой в браузере адрес, который напишет команда (обычно
http://localhost:5173). Остановить — `Ctrl+C` в терминале.

## 5. Проверки — те же, что перед каждой публикацией

    npm test           # правила методики, хранилище, архив
    npm run build      # типы и сборка

Прогон всего сценария со скриншотами (первый раз скачает браузер):

    npx playwright install chromium
    npm run build
    npm run preview &
    npm run shots      # картинки появятся в web/shots/

## Обновить копию

Когда в облаке что-то изменилось:

    cd ~/Projects/punchline
    git pull
    cd web && npm ci

## Где что лежит

    punchline/
      web/          приложение
        src/domain/   правила методики: статусы шутки, сеты, метрики
        src/store/    хранение: база, архив, отмена
        src/ui/       экраны; весь видимый текст — в ui/labels.ts
        tools/        прогон сценария со скриншотами
      docs/         проектные решения и логика методики
      CLAUDE.md     правила работы над проектом (Claude читает его сам)
