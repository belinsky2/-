# Архив: Android-период

Эти документы написаны, когда проект был Android-приложением на Kotlin
(Compose, Room). В сентябре 2026 основной версией стало веб-приложение
(см. `../07-reshenie-o-platforme.md`), а Android-код удалён из репозитория.

Документы оставлены потому, что в них записаны **причины** решений, которые
живы и сейчас:

- `04-arhitekturnyy-razbor.md` — почему идентификаторы UUIDv7, почему удаление
  делается надгробием, зачем логические часы. Всё это есть в `web/src`.
- `05-audit-proekta.md` — почему конфликты решаются на уровне записи.

Стек, сборка APK и инструкции по установке в них устарели.

## Как вернуть Android-код

Последнее состояние с Android-версией — коммит `d53485f`:

    git checkout d53485f -- app core gradle gradlew build.gradle.kts settings.gradle.kts
