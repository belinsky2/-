# Каталог упражнений — seed-данные приложения

Справочник, который приложение загружает из `assets/exercises.json`.
Хранятся **только**: номер, часть книги, короткий ярлык, страница книги, тип формы
и то, какую сущность упражнение порождает. Текстов упражнений и примеров Картер здесь нет —
их пользователь читает в книге, а в приложении заполняет свои ответы.

Названия восстановлены по оглавлению *The NEW Comedy Bible* (2020) из открытых источников.
7 позиций подтвердить не удалось — помечены `❓` и требуют сверки с бумажной книгой;
приложение это переживает: у такой записи ярлык «Упражнение N» и универсальная форма.

## Типы форм (`inputSchema`)

| Тип | Поля | Порождает |
|---|---|---|
| `scale` | слайдер + комментарий | запись в профиль |
| `statement` | одно длинное поле | запись в профиль |
| `list` | список строк, быстрое добавление | Topic / Note |
| `scoring` | список с оценкой каждого пункта | обновление Topic.passionScore |
| `mindmap` | холст с узлами | Bit(seed) |
| `audio` | диктофон + транскрипт | Rant → Bit |
| `bit-field` | выбор шутки + заполнение одного её элемента | обновление Bit |
| `bit-batch` | прогон по нескольким шуткам подряд | обновление Bit[] |
| `setlist` | конструктор сет-листа | SetList |
| `review` | прогон по гигу с оценками | BitPerformance[] |
| `checklist` | чеклист | Note |

## Утренние страницы: 30 промптов

Тетрадь даёт 30 промптов для секции Morning Writings. Их формулировок в открытом
доступе нет. Решение для v1: **приложение не хардкодит чужие промпты**, а даёт
пользователю добавлять свои (`MorningWritingPrompt` — редактируемый справочник),
плюс режим «без промпта» — просто свободное письмо по таймеру.
Когда тетрадь будет на руках, промпты вносятся через экран настроек за 15 минут,
без пересборки приложения.

## Что уточнить по бумажной книге

- Упражнения 20, 23, 24, 25, 44, 47, 48 — названия.
- 30 промптов утренних страниц — названия/формулировки (для личного использования).
- Номера страниц для упражнений 1–31, 34–37, 40, 47, 48 — чтобы кнопка «открыть в книге»
  показывала точную страницу.
