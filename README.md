# Панчлайн

Цифровая рабочая тетрадь стендапа по методике Джуди Картер
(*The NEW Comedy Bible* + *The Comedy Bible Workbook*).

Приложение для личного пользования. Без аккаунтов и без облака: материал
живёт на устройстве. Открывается по ссылке и ставится на домашний экран:

**https://belinsky2.github.io/punchline/**

## Что оно делает

Переносит путь из книги в телефон: поймать мысль → привязать к теме →
собрать шутку (отношение → премиса → сетап → панчлайн → act-out) → поставить
в сет → выйти на сцену → отметить реакцию зала. Статус шутки двигается сам —
по её содержимому и по смеху в зале, а не по ощущениям.

## Как работать

- Поставить на Mac — `docs/mac.md`.
- Проверки: `cd web && npm test && npm run build`, затем прогон сценария
  (`npm run preview &` и `npm run shots`).
- **Публикует ветка `master`.** Каждый пуш в неё прогоняет тесты, сборку и
  сценарий; если хоть что-то красное — не публикуется. Какая версия открыта
  на телефоне, видно в Настройках, карточка «Версия».

## Решения, которые не стоит отменять не подумав

- **Поля синхронизации у каждой записи** (`updatedAt`, `lamport`, `deviceId`,
  `deletedAt`). Задним числом их не добавить: у старых записей неоткуда взять
  историю. На них держится восстановление из архива слиянием.
- **Удаление — надгробие, а не удаление строки.** Иначе удалённое воскресает
  при слиянии.
- **Восстановление из архива сливает, а не перезаписывает.** Старый архив не
  должен стирать сделанное после него.
- **Архив — один JSON, автоархив в момент правки.** Скачивание браузер
  разрешает только в ответ на действие человека.
- **Текстов Картер в приложении нет** — только номер упражнения, ярлык и
  страница.
- **Весь видимый текст в `labels.ts`.** Словарь — жаргон сцены: сетап,
  панчлайн, добивки (теги), опенер, клоузер, тайминг.
