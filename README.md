# Панчлайн

Цифровая рабочая тетрадь стендапа по методике Джуди Картер
(*The NEW Comedy Bible* + *The Comedy Bible Workbook*).

Android-приложение для личного пользования. Без сети, без аккаунтов, без облака.

## Что это делает

Переносит путь из книги в телефон: поймать идею → найти тему → выговориться
вслух → собрать шутку (отношение → премиса → панч → act-out) → поставить в сет →
выйти на сцену → отметить реакцию зала → пересобрать акт по данным, а не по ощущениям.

## Устройство репозитория

```
:core:model   чистый Kotlin, без Android. Доменная модель, жизненный цикл шутки,
              правила сет-листа, метрики, выгрузка в Markdown. Здесь же все тесты
              логики — они гоняются без Android SDK
:core:vault   чистый JVM. Формат хранилища: блобы по SHA-256 и архив переноса.
              В v2 достаётся Mac-приложению без изменений
:core:data    Room, репозитории. Room наружу не выходит: приложение видит
              только фасад DataLayer
:app         Compose UI
```

## Сборка

APK собирается в GitHub Actions на каждый push и лежит в артефактах прогона.
Чтобы он был подписан и устанавливался, нужны четыре секрета репозитория:
`PUNCHLINE_KEYSTORE_BASE64`, `PUNCHLINE_KEYSTORE_PASSWORD`,
`PUNCHLINE_KEY_ALIAS`, `PUNCHLINE_KEY_PASSWORD`.

**Ключ подписи один на всю жизнь приложения.** Android принимает обновление
только от APK с тем же ключом; потеря ключа означает переустановку с потерей
всех данных.

Локально, там где Google Maven недоступен, логику можно прогнать без Android SDK:

```bash
PUNCHLINE_JVM_ONLY=1 ./gradlew :core:model:test :core:vault:test
```

Полная сборка (нужен Android SDK):

```bash
./gradlew :app:assembleRelease
```

## Решения, которые лучше не отменять случайно

- **Нет разрешения `INTERNET`** — и не понадобится после появления синхронизации:
  она пойдёт через папку, которую реплицирует стороннее приложение.
- **Идентификаторы UUIDv7, удаление надгробиями, `updatedAt`/`lamport` в каждой
  таблице, аудио по SHA-256** — это подготовка к слиянию с Mac. Дёшево сейчас,
  очень дорого потом.
- **Текстов Картер в приложении нет** — только номер упражнения, ярлык и страница.
  Это делает приложение чистым для раздачи; не стоит соблазняться зашитыми
  формулировками ради удобства.
- **Ни одной строки видимого текста в коде** — только `strings.xml`. Проверяется
  задачей `:app:checkNoHardcodedCyrillic` в CI.
