# Правила работы над этим проектом

## Публикация: никогда не утверждать без подтверждения

`git push` — это **не** публикация. Между пушем и живым приложением стоят
тесты, типы, сборка и прогон сценария; красный прогон намеренно не публикует.

**Нельзя писать «опубликовано», «готово», «обнови приложение», пока задание
`deploy` в рабочем процессе `web` не завершилось со статусом `success.`**
Проверяется так: найти последний прогон `web.yml` на ветке `master`,
посмотреть задание `deploy`, убедиться в `conclusion: success`.

Эта ошибка уже случалась трижды: дважды с веб-версией (публикация падала на
одной проверке, а сообщение об успехе уходило) и один раз с APK, который
лежал в релизе старым. Каждый раз причина одна — вывод об успехе делался
по промежуточному шагу.

Если публикация упала — сказать об этом прямо и не выдавать частичный
результат за целый.

## Версия видна в приложении

Настройки показывают дату сборки и коммит. Это сделано ровно для того, чтобы
слова о публикации проверялись владельцем за две секунды. Не убирать.

## Что проверяется само

    cd web
    npm test        # домен, правила архива, хранилище
    npm run build   # типы и сборка
    npm run preview &
    npm run shots   # прогон сценария, картинки в web/shots/

Прогон — не формальность: он трижды находил то, чего не видели юнит-тесты
(отметки зала не двигали статус шутки; правка обкатанной шутки роняла её в
черновик; отметить можно было только шутку из сет-листа).

**Смотреть на скриншоты глазами.** Склонения («1 дней подряд»), мёртвые
кнопки, отсутствующие поля и текст, который врёт о поведении, — всё это
проходит мимо любых автоматических проверок.

## Границы, которые не двигать без разговора

- **Текстов из книги Картер в приложении нет.** Только номера упражнений,
  короткие ярлыки и страницы. Всё остальное пишет автор.
- **Материал не теряется.** Поля синхронизации у каждой записи, удаление —
  надгробие, а не удаление строки, архив уходит в Загрузки сам.
- **Весь видимый текст — в `web/src/ui/labels.ts`.** Строки, расползшиеся по
  коду, потом не переформулировать разом.
- **Kotlin в `core/model` и `core/vault` — эталон правил** при расхождении с
  переносом в `web/src/domain/`.
